# Kiro IDE 体験ハンズオン 🚀

## 概要

* このハンズオンでは、AI コーディング IDE「**Kiro**」の基本的な使い方を約1時間で体験します。自然言語で指示を出すだけでアプリケーションが完成する「Vibe コーディング」を中心に、Kiro の威力を実感してください。

* なお、このハンズオンで Kiro に興味を持ち、「もっと知りたい、使ってみたい」という場合は、別途ワークショップなどのご提案も可能ですのでご相談ください！

## 利用する環境

* インストラクターよりガイドします。下記のいずれかのケースになります。
    - ケース 1. トレーニングコースのラボ環境を使用する
    - ケース 2. AWS Skill Builder のラボ環境を使用する
        - (このラボの使用には、Skill Builder のサブスクリプションが必要です。）
        - **ラボ**: [Lab - Structured Approach to AI coding with Spec-Driven Development on Kiro](https://skillbuilder.aws/learn/J74A9BP8SM/lab--structured-approach-to-ai-coding-with-specdriven-development-on-kiro/VDK8N2DMKC)
    - ケース 3. インストラクターが用意する AWS アカウントを使用する
        - [こちら](https://d-9567586b55.awsapps.com/start) からアクセス
        - サインインに必要な情報はインストラクターからガイドします。

* 上記いずれのケースでも受講者の AWS Builder ID で Kiro にサインインして、Free Plan のクレジットを使用いたします。
    - このハンズオンの Vibe モードで基本機能だけを実装する場合は、約 1.5 ～ 2.5 ほどのクレジットを消費します。 

> ⚠️ **注意**: Kiro の Free Plan のクレジットには制限があります。クレジットについてはインストラクターから説明します。

### ハンズオン環境の特徴

- Kiro がプリインストール済み
- Node.js がインストール済み
- AWS Builder ID でのサインインが可能
- ブラウザベースで動作するため、ローカル環境のセットアップ不要

### ハンズオンの起動手順

#### ケース 1. の場合
1. myClass からコースとラボを選択して、ラボを起動します。
1. ラボのガイドにもとづき、Kiro がインストールされたインスタンスへアクセスします。   

#### ケース 2. の場合
1. 上記リンクから AWS Skill Builder にアクセスします。
1. Skill Builder のラボを開始（Start Lab）します。
1. ラボ環境内の手順に従い環境にアクセスします。
1. この後、Vibe コーディングの手順に進みます。

#### ケース 3. の場合
1. 上記リンクから AWS アカウントへサインインします。
1. マネジメントコンソールで東京リージョン (ap-northeast-1) を選択します。
1. ブラウザで新しいタブを開き、下記の URL にアクセスします。
    - `https://aws-samples.github.io/sample-one-click-generative-ai-solutions/solutions/kiro-ide/`
1. Kiro IDE Remote のページが表示されることを確認します。
1. ページを少し下にスクロールして、「**AWS へのデプロイ**」で「**東京**」が選択されていることを確認し、「**Deploy**」をクリックします。
1. 「**パラメータ**」セクションの「**UserEmail**」に下記を入力します。
    - `tetsuo.nobe.10031127+(自分のID)@gmail.com`
    - (自分のID)の箇所は ID 値に置き換えてください。例: tetsuo.nobe.10031127+01@gmail.com
1. 「**機能**」セクションのチェックボックスをチェックします。
1. ページ右下の「**スタックの作成**」をクリックします。
1. マネジメントコンソールで CloudFormation のページで、「**スタックの情報**」タブをクリックします。
1. 「**ステータス**」が「**CREATE_COMPLETE**」になるまで待ちます。
    - 約13分ほどかかります。
1. 「**出力**」タブをクリックします。
1. 下記の値をメモします。
    - **KiroIDEURL**: Kiro IDE へのアクセス URL
    - **Username**: ログイン用のユーザー名
    - **Password**: ログイン用のパスワード
1. ブラウザで新しいタブを開き、**KiroIDEURL** にアクセスします。
1. メモしておいた **Username** と **Password** でサインインします。
1. ブラウザに Ubuntu デスクトップが表示されることを確認します。
    - **注意**: Ubuntu デスクトップでは、**全角と半角の入力切り替え**は、**Ctrl + Space** であることを覚えておいてください。 
1. この後、Vibe コーディングの手順に進みます。

## 推奨する進め方

### 必須: Vibe コーディング（30〜40分）

まずは Vibe セッションで「自然言語だけでアプリを作る」体験をします。

- ステアリング（日本語ルール）の設定
- AWS サービスに関する4択クイズアプリの生成
- 追加機能の依頼と反復改善

👉 **[Vibe コーディング ハンズオンへ進む](./vibe/README.md)**

### オプション: Spec モード（30〜40分）

Kiro クレジットや時間に余裕がある場合は、Spec セッション（構造化ワークフロー）も体験してみましょう。Vibe モードとの違いを理解できます。

- 要件定義 → 設計 → タスク分解 → 実装の段階的プロセス
- アメリカの都市の天気情報を表示する Web アプリを構築
- チーム開発・品質重視のケースに適した進め方

👉 **[Spec モード ハンズオンへ進む](./spec/README.md)**

## Kiro の2つのセッションモード

| 観点 | Vibe モード | Spec モード |
|------|------|------|
| 進め方 | 会話しながら即座にコード生成 | 要件→設計→タスク→実装の段階的プロセス |
| 適したケース | 小規模・プロトタイプ・実験 | 中〜大規模・チーム開発・品質重視 |
| 成果物 | コードのみ | 要件書 + 設計書 + タスク一覧 + コード |
| 変更管理 | 会話履歴に依存 | 仕様書として残る |
| 本ハンズオン | AWS クイズアプリ | 天気アプリ |

```
┌─────────────────────────────────────────────┐
│  アイデア段階 / プロトタイプ → Vibe モード     │
│  本格開発 / チーム開発     → Spec モード      │
└─────────────────────────────────────────────┘
```

## Kiro の主な機能一覧

| 機能 | 説明 | ハンズオンでの体験 |
|------|------|------|
| Vibe セッション | 会話形式でコードを生成・修正 | ✅ 必須パートで体験 |

| MCP | 外部ツール連携（AWS ドキュメント検索など） | - |

## FAQ

| 質問 | 回答 |
|------|------|
| ラボの利用時間が足りない場合は？ | Vibe コーディング（必須パート）を優先してください。Spec モードはオプションです |
| ラボ環境以外でも実施できる？ | Kiro をローカルにインストールすれば可能です。Node.js のインストールも必要です |
| AWS の知識がなくても大丈夫？ | はい。Kiro の操作体験が目的なので、AWS の深い知識は不要です |

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| ラボが起動しない | AWS Skill Builder にログインしているか確認。ブラウザのポップアップブロックを無効にする |
| Kiro にサインインできない | AWS Builder ID のアカウントが必要です。ラボの手順に従ってサインインしてください |
| 生成されたファイルが見つからない | Kiro 左側のエクスプローラーアイコンをクリックしてファイルツリーを確認 |
| Kiro が英語で応答する | ステアリングの設定手順を再確認。設定後は新しいセッションを開始してください |
